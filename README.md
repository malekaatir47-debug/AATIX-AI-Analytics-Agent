# 🤖 AATIX AI Analytics Agent

Autonomous AI-powered data analytics pipeline that automatically cleans, analyzes, visualizes, and generates structured insight reports from raw datasets with production-level error handling.

---

## 🚀 Overview

AATIX AI Analytics Agent is a production-ready data analytics system built in Python.  
It performs end-to-end automated data analysis including:

- Data loading (CSV, Excel, JSON, Parquet)
- Intelligent data cleaning
- Outlier detection and handling
- Correlation analysis
- Statistical profiling
- Visualization generation
- Automated insight generation
- JSON & Markdown report export

The entire process runs autonomously with robust error handling.

---

## 🧠 Features

- Automatic missing value handling
- Duplicate removal
- Outlier capping using Z-score
- Correlation detection with threshold alerts
- Statistical summary generation
- Heatmap visualization
- Distribution plots
- Missing value analysis
- JSON report export
- Markdown report generation
- Safe execution wrapper
- Logging and error tracking

## ▶ Installation

Clone the repository:

git clone https://github.com/yourusername/AATIX-AI-Analytics-Agent.git

Navigate to the project folder:

cd AATIX-AI-Analytics-Agent

Install dependencies:

pip install -r requirements.txt

---

## ▶ Usage

Run the complete pipeline:

python aatix_agent.py

Or analyze a custom dataset:

analyze_csv_file("your_dataset.csv")
